# LakUkl1A
Program ini berfungsi untuk menghitung biaya pengiriman berdasarkan berat, jarak, dan ukuran paket. Pengguna memasukkan data paket, lalu program menghitung volume, menentukan tarif per kg, menambah biaya jika volume lebih dari 100 cm³, dan menampilkan total biaya dengan cara cepat dan mudah dipahami.
